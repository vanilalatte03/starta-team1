# @ManyToOne 팀원 소개 페이지 만들기

### 프로젝트 소개

각 팀원이 자기소개 내용을 작성하고 이를 하나의 소개 페이지로 모아보는 협업 과제입니다.  
Git 브랜치 전략, Pull Request 생성, 코드 리뷰, 병합 과정을 직접 경험하는 것을 목표로 합니다.

### 진행 목표
- 각자 작업 브랜치를 생성한다.
- 본인 소개 내용을 담은 `md` 파일을 작성한다.
- Pull Request를 생성하고 팀원들과 리뷰를 주고받는다.
- 리뷰가 완료된 내용을 병합한다.
- 최종적으로 팀원 소개 내용을 바탕으로 웹페이지를 작성한다.

## 역할 분담

### HTML
- `feature/header-nav` — 임선규  
  - 상단 네비게이션, 하단 footer HTML
- `feature/member-cards-html` — 양지원  
  - 멤버 카드 HTML

### CSS
- `feature/layout-style` — 조민재  
  - 전체 레이아웃 스타일
- `feature/card-style` — 정욱재  
  - 멤버 카드 스타일

### JavaScript
- `feature/card-interaction` — 민병준  
  - 디테일 버튼 클릭 시 토스트 메시지 출력
