# @ManyToOne 팀원 소개 페이지 만들기

### 프로젝트 소개

각 팀원이 자기소개 내용을 작성하고 이를 하나의 소개 페이지로 모아보는 협업 과제입니다.  
Git 브랜치 전략, Pull Request 생성, 코드 리뷰, 병합 과정을 직접 경험하는 것을 목표로 합니다.

## 진행 목표
- 각자 작업 브랜치를 생성하고 맡은 기능을 구현한다.
- Pull Request를 생성하고 팀원들과 리뷰를 주고받는다.
- 리뷰 내용을 반영한 뒤 `master` 브랜치에 병합한다.
- 최종적으로 팀 소개 내용을 하나의 웹 페이지로 정리한다.

## 파일 구조
```text
web/
├── index.html
├── style.css
├── script.js
└── images/
```
## 파일별 담당 역할

- `web/index.html`
  - 기본 파일 구성 및 연결 → 임지호
  - 상단 네비게이션 및 하단 footer HTML → 임선구
  - 멤버 카드 HTML 작성 → 양지원

- `web/style.css`
  - 전체 레이아웃 스타일 작성 → 조민재
  - 멤버 카드 스타일 및 디자인 마무리 → 정욱재

- `web/script.js`
  - 카드 디테일 버튼 클릭 시 토스트 메시지 기능 구현 → 민병준

- `README.md`
  - 결과 정리 및 문서화 → 임지호
    
## 협업 방식
1. `master` 브랜치에서 `develop` 브랜치를 생성하고, 협업을 위한 공통 작업 브랜치로 사용했습니다.
2. 각 팀원은 `develop` 브랜치를 기준으로 기능 브랜치를 생성해 맡은 작업을 진행했습니다.
3. 작업 완료 후 `develop` 브랜치로 Pull Request를 생성했습니다.
4. 팀원들과 코드 리뷰를 주고받으며 수정 사항을 반영했습니다.
5. 리뷰가 끝난 작업은 `develop` 브랜치에 순차적으로 병합했습니다.
6. 모든 작업이 완료된 뒤 `develop` 브랜치의 최종 결과를 `master` 브랜치에 병합했습니다.

## 실행 방법
1. 저장소를 clone 합니다.
2. `web/index.html` 파일을 브라우저에서 실행합니다.

## 최종 결과
- 헤더, 멤버 카드, 푸터를 포함한 팀원 소개 페이지를 반응형으로 구현했습니다.
- 카드 버튼 클릭 시 "아직 준비중입니다." 토스트 메시지가 출력되도록 구현했습니다.
